# WoW Color Note

A speed-first offline Android note app inspired by the simplicity of ColorNote, with Myanmar calendar support, custom fonts, fast edit/preview, folders, colors and local SQLite storage.

## Design goals
- Instant startup and note opening
- Unlimited local notes (device-storage limited)
- Lightweight native Android Views (no Compose runtime)
- Reliable Edit / Preview for very long notes
- Myanmar calendar data
- Import and use custom TTF/OTF fonts
- Premium theme family shared with other WoW apps

## Build
Open with Android Studio (JDK 17) or run the GitHub Actions Android workflow.
